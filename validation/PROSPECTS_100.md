## Как пользоваться

1. **Wave 1 (дни 1–3):** только `fit=high` — агентства 2–25 человек + фрилансеры с retainer.
2. **Wave 2:** `fit=med`.
3. **Wave 3 / skip:** `fit=low` (холдинги) — не тратить первые сообщения.
4. На каждый контакт завести строку в трекере: ответил / интервью / боль часы / готов платить / preorder.
5. CSV для импорта: `prospects_100.csv`.
