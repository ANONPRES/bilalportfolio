## За 3–7 дней

1. Задеплойте `validation/` (любой static host).
2. Подключите сбор email (Formspree / Buttondown / Tally) вместо localStorage в `app.js`.
3. Отправьте **50** холодных сообщений только `fit=high` (шаблоны в playbook).
4. Проведите интервью по сценарию 15 мин.
5. Сверьте с PASS/FAIL в `SALES_PLAYBOOK.md` — без «ещё недельки» на ощущениях.

## Холодные сообщения

### LinkedIn / email

```
Привет, {Name}. Вижу, у {Agency} {N} retainer-клиентов.

Вопрос на 20 секунд: сколько часов в месяц уходит на клиентские отчёты
(не на работу, а именно на сбор GA4/Ads + текст «что это значит»)?

Спрашиваю, потому что собираю waitlist на узкий инструмент:
GA4 → готовый клиентский PDF с выводами (без ещё одного дашборда).

Если боль знакома — ответьте цифрой часов. Если нет — скажите «не болит».
```

### Follow-up через 3 дня

```
{Name}, коротко догоняю.

Если отчёты — боль: могу показать оффер пилота $49/мес (до 5 клиентов)
и взять в первые 10 агентств. Если не болит — ок, не буду писать.
```

## Интервью (20 мин)

1. Сколько retainer-клиентов? Средний чек?
2. Как сейчас monthly report? Инструменты?
3. Часов на 1 клиента? Кто пишет текст?
4. Что клиент читает / игнорирует?
5. Платите ли DashThis/AgencyAnalytics/Whatagraph?
6. GA4→PDF с выводами за $49/mo на 5 клиентов — купили бы на этой неделе?
7. Что must-have в v1?

## Pass / Fail

| Сигнал | Pass | Fail |
|---|---|---|
| Ответы | ≥15/50 | <10% |
| Боль ≥3ч/клиент | ≥8 | <5 |
| «Возьму за $49» | ≥5 | только «интересно» |
| Prepay / card | ≥3 waitlist card или ≥2 deposit | 0 |

**Fail → не кодить.** Перейти к Пути 1 (niche IDE extension) из research-дока.
